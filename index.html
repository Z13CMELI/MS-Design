Act III · The Interaction Engine
Three primitives.
Every workflow.
WHEN + IF → THEN. The same three-zone grammar applies to every operational gesture — from routine replenishment to the most complex seasonal exception.
Universal Grammar

Not by persona.
By gesture and by routine.

The alternative to designing by persona is designing around what the work actually is: a repeatable sequence of gestures, structured like an algorithm, calibrated to an operational tempo. We called this model GestureOps — three structural zones, one temporal rhythm, any planner, any domain.

Dimension 1 · Structure

Think in gestures

Every interaction is a conditional sequence — the same logic as an algorithm, but driven by a human. Each gesture has an explicit context, a readable consequence, and a clear decision point.

WHEN I define my scope: zone, season, product family. Context is always explicit before anything else.
IF I read what's happening and simulate what my next action would change — before committing it.
THEN I act — or I let the algorithm run. Either way, the decision is traceable.
Scope Bar → Evidence Zone → Exception Tray
Dimension 2 · Tempo

Think in routines

The same sequence repeats daily, weekly, every season. The interface is shaped around this operational tempo — not around a feature list per role.

Alert
Anomaly flagged by the system, or proactive investigation by the planner
Analyze
Read the evidence. Understand the real impact before touching anything.
Decide
Human judgment applied to a pre-computed simulation — not a guess.
Act — or stand down
The algorithm takes back control. With or without an override, the gesture is complete.
Two readings, one model — WHEN + IF → THEN, repeated across every operational routine

Annexe F · Incidents
Automation without interface

It can only fail in two ways.

These incidents happened when the only environment available to ZDPs was raw SAP screens. In both cases, the algorithm executed correctly. What failed was the absence of an interface between the human and the machine.

Case 01 · Silence

Zero stock dispatched.
Zero alerts triggered.

A SAP formatting issue dropped leading zeros from a product family code. The replenishment algorithm silently skipped the entire family — for weeks. Nobody noticed. The system produced complete silence.

Logistical cascade
1 CARs receive no stock for affected family
2 Stores report gradual stockouts — cause unknown
3 No alert. No flag. Weeks pass before discovery.
Case 02 · Excess

14,000 product-warehouse
pairs altered overnight.

A planner adjusted a rule for a single depot. Because the interface never made the boundary explicit, the algorithm applied the rule across an entire regional distribution center in a single overnight batch run.

Logistical cascade
1 Entire zone: 14,000 settings overwritten in one night
2 Massive excess stock shipped to wrong CARs
3 Manual rollback required across 3 logistics teams
